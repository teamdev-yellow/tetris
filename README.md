# tetris - チーム開発課題
JavaScript、 HTML、 CSSを用いて実装された世界的に有名なゲーム「テトリス」です。
このブラウザで遊べるテトリスゲームは、レベルとスコアのシステムを導入しており、プレイヤーはラインを消去することで得られるポイントや、レベルアップに応じた落下速度の変化を体験できます。
高得点を狙うための工夫をしながら、ぜひゲームを楽しんでみてください。

矢印キーでテトリミノを操作：<br>
◀︎　/　▶︎：水平移動 <br>
▼：ソフトドロップ <br>
▲：時計回りに回転 <br>

##レベルシステム
・レベルの上昇条件:各レベルごとに一定数のラインを消去することで、次のレベルに進みます。
10ライン消去ごとに次のレベルに移行します。
レベル0からスタートし、最高レベルは15です。
・レベルに基づく落下速度:レベル1では落下速度は1秒です。各レベルにおけるブロックの落下速度は、
落下時間 = 初期時間 × (0.8 - ((レベル - 1) × 0.007)) ^ (レベル - 1)です。

## スコアシステム
・スコア加算の基本ルール:
ライン消去による基本スコア：1度に消去するライン数に応じてスコアが加算されます。

1ライン消去: 100ポイント
2ライン消去: 300ポイント
3ライン消去: 500ポイント
4ライン消去（テトリス）: 800ポイント
レベルによるスコア倍率：ゲームのレベルが上がるごとに、各アクションに対するスコアは倍率がかかり、高い得点が得られます。
スコア = 基本スコア × 現在のレベル

・ボーナススコア:
バック・トゥ・バック:テトリスを連続して行った場合、通常のスコアに対して1.5倍の得点が与えられます。
コンボ:連続してラインを消去するたびに、コンボとして追加スコアが獲得されます。
1回目のコンボ: 50ポイント
2回目のコンボ: 100ポイント
3回目のコンボ: 150ポイント
4回目以降: 50ポイントずつ加算されます。（例: 200, 250, 300...）

## アーキテクチャ
このプロジェクトでは、モジュール化された構造を採用しており、各ファイルは特定の機能を提供しています。
この設計により、コードの可読性やメンテナンス性が向上し、チーム開発を効率的に行うことが可能になっています。
また、イベント駆動型のアプローチを採用することで、ユーザーの操作に即応した柔軟な動作が実現されています。


- `index.html`: ゲームのメインHTMLファイルです。
- `src/css/style.css`: ゲームのメインHTMLファイルです。
- `src/assets/audio`: ゲームで使用する画像や音声ファイルが保存されています。
- `src/js`: ゲームのロジックに関わるソースコードを格納するディレクトリ。
  - `audio.js`: 音声ファイルの管理と再生を担当します。
  - `controls.js`: ユーザーからの入力を処理します。
  - `display.js`: ゲーム画面の描画を担当します。
  - `game.js`: ゲームのロジックや進行を管理します。
  - `main.js`: ゲームの初期化を行います。
  - `playground.js`: ゲームフィールドの状態を管理し、テトリミノの配置を追跡します。
  - `score.js`: スコアやレベルアップのロジックを実装し、ゲーム進行に伴う得点を管理します。
  - `tetrimino.js`: テトリミノの生成と操作を行います。
