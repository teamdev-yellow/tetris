# tetris - チーム開発課題
JavaScript、 HTML、 CSSを用いて実装された世界的に有名なゲーム「テトリス」です。

## 遊び方
矢印キーでテトリミノを操作：<br>
◀︎　/　▶︎：水平移動 <br>
▼：ソフトドロップ <br>
▲：時計回りに回転 <br>
スペース：ハードドロップ <br>
ホームボタン：ゲーム終了 <br>

## アーキテクチャ
このプロジェクトでは、モジュール化された構造を採用しており、各ファイルは特定の機能を提供しています。
この設計により、コードの可読性やメンテナンス性が向上し、チーム開発を効率的に行うことが可能になっています。
また、イベント駆動型のアプローチを採用することで、ユーザーの操作に即応した柔軟な動作が実現されています。


- `index.html`: ゲームのメインHTMLファイルです。
- `src/css/style.css`: ゲームのメインHTMLファイルです。
- `src/assets/audio`: ゲームで使用する画像や音声ファイルが保存されています。
- `src/js`: ゲームのロジックに関わるソースコードを格納するディレクトリ。
  - `audio.js`: 音声ファイルの管理と再生を担当します。
  - `controls.js`: ユーザーからの入力を処理します。
  - `display.js`: ゲーム画面の描画を担当します。
  - `game.js`: ゲームのロジックや進行を管理します。
  - `main.js`: ゲームの初期化を行います。
  - `playground.js`: ゲームフィールドの状態を管理し、テトリミノの配置を追跡します。
  - `score.js`: スコアやレベルアップのロジックを実装し、ゲーム進行に伴う得点を管理します。
  - `tetrimino.js`: テトリミノの生成と操作を行います。



## 学んだこと
1.  チーム開発におけるGit・Githubの活用<br>
複数人で共同作業する際のGitの使用方法について理解が深まりました。
    -  新しいコマンドの学習：stashコマンドを利用して、作業中の変更を一時的に退避させ、リポジトリの状態を元に戻す方法を学びました。
    - ブランチ命名規則：各開発者がどの作業を行なっているのかを明示的に分かるようにするために、ブランチ命名規則を設けてそのブランチの目的や内容をすぐに理解できるようにすることの重要性を実感しました。
    - コンフリクトの解決：コードの競合が発生した際に、チームメンバーのコードと自分のコードを照らし合わせて解決する方法を学びました。<br>

2. モジュール化と作業分担<br>
プロジェクトを機能ごとにモジュール化することで、コードの再利用性を向上させました。
また、各機能を分離して開発することで、チーム内での作業分担が容易になりました。
